## Glossary

**AI**: Artificial intelligence refers to the development of computer systems that can perform tasks that typically require human intelligence, such as understanding language, recognizing images, and making decisions. In the context of large language models, AI is used to enable machines to understand and generate human-like language.

**Chatbot**: A chatbot is a computer program designed to simulate conversation with human users, either through text or voice interactions. Examples of chatbots include Eliza and Chat GPT, which demonstrate the progression of natural language processing capabilities.

**Closed-Source Model**: A closed-source model refers to a type of artificial intelligence model where the architecture and weights of the model are not publicly available, restricting access to the model's internal workings. Examples of closed-source models include those released by Open AI.

**Deep Learning**: Deep learning is a subfield of machine learning that involves the use of neural networks to analyze and interpret data, such as images, speech, and text. In the context of large language models, deep learning is used to enable machines to learn and generate human-like language.

**Eliza**: Eliza is an early chatbot developed in the 1960s, designed to simulate a therapist by responding to user input with simplistic and vague responses. Eliza represents one of the first attempts at creating a natural language processing system.

**Generative AI**: Generative AI refers to a type of artificial intelligence that enables machines to generate new content, such as text, images, videos, and audio, based on patterns and structures learned from existing data. Large language models are a key application of generative AI.

**GP4**: GP4, also known as GPT-4, is a closed-source large language model released in 2023, which demonstrated impressive functionality and had a significant impact on the field of natural language processing.

**Large Language Model (LLM)**: A large language model is a type of artificial intelligence model designed to process and generate human-like language, typically using deep learning techniques and large amounts of training data. LLMs have the ability to understand and respond to complex user input.

**LLaMA 3.1**: LLaMA 3.1 is an open-source large language model released by Facebook, which performs on par with closed-source models like GP4. LLaMA 3.1 demonstrates the advancements in open-source models and the narrowing gap between open-source and closed-source models.

**Machine Learning**: Machine learning is a subfield of artificial intelligence that involves the development of algorithms and statistical models that enable machines to learn from data, without being explicitly programmed. Machine learning is a key component of large language models.

**Natural Language Processing (NLP)**: Natural language processing refers to the field of study focused on enabling machines to understand, interpret, and generate human language, including tasks such as language translation, text summarization, and sentiment analysis.

**Neural Network**: A neural network is a type of machine learning model inspired by the structure and function of the human brain, consisting of layers of interconnected nodes (neurons) that process and transmit information. Neural networks are a key component of deep learning and large language models.

**Open-Source Model**: An open-source model refers to a type of artificial intelligence model where the architecture and weights of the model are publicly available, allowing anyone to access and learn from the model's internal workings. Examples of open-source models include LLaMA 3.1.

**Text Generation**: Text generation refers to the ability of machines to create human-like text based on patterns and structures learned from existing data. Large language models are capable of generating coherent and context-specific text.

**Video Generation**: Video generation refers to the ability of machines to create realistic videos based on patterns and structures learned from existing data. Generative AI has enabled the creation of stunningly realistic AI-generated videos.

**YouTube Channel (VIUA)**: VIUA is a YouTube channel created by Dr. Raj Dander, aiming to make AI accessible to everyone by providing comprehensive guides to building large language models from scratch, without assuming prior knowledge.
